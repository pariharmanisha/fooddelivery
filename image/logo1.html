Your HTML is mostly correct. The main errors are:

1. Wrong JavaScript file name ❌

You wrote:

HTML
<script src="aap.js"></script>

If your file is named app.js, it should be:

HTML
<script src="app.js"></script>

2. Check the image path

You wrote:

HTML
<img src="image/background.png" alt="food">

Make sure your folder structure is:

project/
│── index.html
│── style.css
│── app.js
│
└── image/
    └── background.png

If the image is in an images folder instead, use:

HTML
<img src="images/background.png" alt="food">

3. Search button type

Inside a form, it's better to specify the button type:

HTML
<button type="button">🔍</button>
